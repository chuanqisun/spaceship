text / tray 2 — tmux status line

Borrowed from tmux and vim statuslines: a solid mode block on the left, a dense run of one-letter keys, a toggle on the right, all on a 14px band with no border. The idea is to remove what only matters while text is arriving. Rate and first chunk live inside the orange STREAM block and disappear with it; idle shows a white IDLE block and nothing else about the model. Labels shrink to the single letter a tmux user would bind.

band
14px tall (was 31px), 9px type with line-height equal to the band, no border or vertical padding. Background ink-5 so it reads as a band without a rule.
mode block
uppercase, tracked +0.06em, solid fill with a 6px powerline wedge. IDLE: white on black. STREAM: orange, followed by rate and first chunk in lowercase (an ellipsis until the first chunk lands).
removed
rate and first chunk while idle. They describe the last stream and go stale as soon as it ends.
w b s p
words, boxes, steering, pinned. Single-letter keys in ink-3, values in ink. Buffer folds into words as +n, orange while it grows.
♪ segment
right-hand wedge, filled ink-4 when on and unfilled when off.
