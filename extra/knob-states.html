text / main knob — buffer states

Whether generated words are waiting past the main knob, shown on the knob itself. It uses only marks the page already has: hairlines, the pip, dashes for "not there yet", fills that show an amount, and orange only while something is changing. Each idea must stay readable alongside every existing state: hover ring, generating arc, holding, and the hollow dragging reticle.

01inner gauge

A 2px arc runs clockwise inside the rim from twelve o'clock, as long as the buffer is full. It is the future knobs' conic fill, cut down to a ring so the knob stays hollow. Empty leaves the plain ring. The arc is white at rest and turns orange while the model writes into it.

02dashed rim

Binary. While text waits past the knob, the rim is solid. When nothing is left, the rim goes dashed, the same mark this page uses for what is not there yet (future knobs, their links, steering behind the knob). The pip stays solid, so the knob still reads as the caret. Risk: a dashed main knob looks like a 12px future knob, and only its size and the pip set it apart.

03lead line

A hairline leaves the knob's right side, into the text ahead, the same mark as the rail's ruler ticks. Its length shows the buffer: up to 24px for a full 300 words. Empty draws a 7px vertical end stop beside the knob instead, meaning the text ends here. While generating, the line's far end is orange where words are arriving. It is the only idea that shows both empty and how much without touching the knob itself.
